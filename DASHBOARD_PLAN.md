# Дашборд Streamlit

Студент 3 реализует `app.py`, `queries.py`, `eda.py` и `charts.py`. Студент 1 предоставляет историю, каталог, календарь и журнал качества в SQLite. Студент 2 поставляет предсказания, метрики и прогнозный выпуск по согласованным ключам. [Контракты SQLite](INTERFACES.md#sqlite-schema).

## Фильтры и разделы

Боковая панель содержит тип скважины, скважину, параметр и диапазон дат. Скважины берутся из каталога по типу. Параметры обновляются при смене скважины и определяются применимостью по каталогу. Даты по умолчанию показывают последние две недели доступного периода. Правая граница выбранной даты включается целиком. Фильтр истории и backtest применяется к метке наблюдения или `target_ts`. При выборе фонтанной скважины список показывает её датчики, включая `line_pressure` NK-75 даже в периоде без данных. В разделе прогноза добавляются горизонт 1–24 и переключатели моделей. Для EDA сравнения нескольких скважин можно выбрать несколько рядов с одинаковым параметром и единицами.

| Раздел | Данные и компоненты | Действия пользователя |
| --- | --- | --- |
| История и EDA | История из `measurements_long` на календаре. Описательная таблица по скважинам и типам с count, mean, median, std, min, max и квартилями. Для сравнения двух типов сводка покрытия и качества использует общие определения. Сравнение значений группируется по одному параметру и единицам. | Менять фильтры, смотреть разрывы и флаги, выбирать исходный или очищенный режим для EDA, переключать период тренда день / месяц. |
| Качество данных | Пропуски по каталогу и календарю, SQL-интервалы, частоты флагов и список проблем. Сохранённые значения доступны при переключении на исходные данные. Для площади и NK-7 предусмотрены быстрые переходы к релевантным скважине, параметру и периоду. | Выбрать месяц или скважину, посмотреть интервал сбоя, сверить флаг и исходное значение. |

## Пять интерактивных визуализаций

| График | Что показывает | Источник и взаимодействие |
| --- | --- | --- |
| 1. Временной ряд | Часовые факты, разрывы, маркеры флагов, дневной или месячный тренд. Для площади и NK-7 отмечены даты смены масштаба и режима. | История, `quality_issues`, агрегаты. Zoom, hover с `timestamp`, `n_obs`, флагом и единицей. |
| 2. Профиль по часу суток | Медиана и межквартильный диапазон для выбранного параметра по скважинам. | `eda.py` из SQLite. Hover показывает число наблюдений. Разные параметры и единицы показываются отдельными выборами. |
| 3. Матрица корреляций | Spearman для параметров выбранной скважины на совпавших часах, по выбранному периоду. | Wide или исходные наблюдения в соответствии с режимом EDA. Hover показывает число пар. Если (n < 30) или один ряд константный, ячейка пуста. Периоды площади можно изучать раздельно. |
| 4. Покрытие по дням | Тепловая карта скважина × день для выбранного параметра. Для сравнения типов доступно общее дневное покрытие применимых параметров по скважине с подписью знаменателя. | Каталог × календарь и факт. Hover показывает ожидаемые, наблюдаемые и помеченные значения. Неприменимость имеет своё состояние. |
| 5. Факт, прогноз и MAE | В режиме backtest верхняя панель показывает факт и прогнозы на выбранном горизонте, нижняя — MAE по горизонтам. В режиме одного выпуска верхняя панель показывает 24 точки на модель с меткой выпуска и фактом там, где он уже есть в архиве. | `backtest_predictions`, `metrics`, `forecast_path`. Hover, переключение моделей и режима, выбор горизонта. |

Покрытие выбранного интервала и EDA вычисляются по его границам. Панель MAE подписана «Официальный test» и показывает метрики всего тестового периода. При фильтре даты вне `test` график backtest показывает пустое состояние, а фиксированная панель MAE сохраняет свою подпись и период. При переключении на один выпуск окно графика строится вокруг выпуска автоматически, с явной датой и отметкой конца архива. [Plotly в Streamlit](https://docs.streamlit.io/develop/api-reference/charts/st.plotly_chart).

## Интеграция и состояния

- `queries.py` открывает SQLite для чтения и использует связанные параметры запроса. Состояния фильтров восстанавливаются только для значений из текущего каталога. Линии истории разрываются на `NULL`. Исходный режим EDA показывает численно корректные `value` из long до маски качества. Отвергнутые при валидации исходные строки доступны в деталях журнала через ссылку на raw.
- Для неполной схемы сообщить о несовместимой БД и предложить пересборку. Для корректной схемы показывать состояния из таблицы ниже. Панель MAE использует весь официальный тестовый период.
- Числа и графики на защите читаются из БД, собранной на опубликованных CSV. Для компонентных тестов используется отдельная БД fixture.

| Состояние | Реакция | Проверка U06 |
| --- | --- | --- |
| Файл БД отсутствует | Показать путь и команду сборки. Селекторы недоступны. | Передать отсутствующий путь. Проверить сообщение и отсутствие нового файла. |
| Корректная БД без результатов | История и аудит доступны. В прогнозе показать «Прогнозы ещё не рассчитаны» и команду полного прогона. | Оставить три таблицы результатов пустыми. Проверить историю и прогноз. |
| Выбранный период пуст | Показать выбранный интервал и отсутствие данных для этого графика. Сохранить фильтры и панель официального MAE, если она доступна. | Выбрать даты вне архива и отдельно вне test. |
| Параметр не поддерживается прогнозом | Показать историю параметра и указать, что прогноз доступен для `pump_fillage` насосных скважин. | Выбрать фонтанную скважину и давление. |

Считать выпуск устаревшим при `origin_ts < test_end`. | Сверить NK-91 с концом архива. Ожидаемая давность — 38 часов. В fixture проверить также выпуск с `origin_ts = test_end`. |
